# HR Analytics: Job Change of Data Scientists

`aug_train.csv` from Kaggle: https://www.kaggle.com/datasets/arashnic/hr-analytics-job-change-of-data-scientists
(Kaggle user `arashnic`, license **CC0: Public Domain**).

19,158 candidates who took data science courses. `target = 1` means the candidate is looking for a new job, `0` means not.
Used in task 1.3 (`1.3/1_3_hr_job_change_nn.ipynb` and `1.3/1_3_hr_job_change_decision_forests.ipynb`).
